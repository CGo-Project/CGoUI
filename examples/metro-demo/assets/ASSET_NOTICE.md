# Demo Asset Notice

The image files in this directory are project-generated demonstration artwork created for the CGoUI open-source example.

They are not copied from, extracted from, or presented as assets of any real transit operator. They intentionally avoid official operator logos, service marks, route maps, notices, hotline information, registration identifiers, and other operator-specific branding.

These images are provided only as generic interface-demo artwork alongside the CGoUI project.
